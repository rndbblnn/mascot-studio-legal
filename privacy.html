Privacy Policy — Mascot Studio

Last updated: 2026-05-10

This application is a personal-use automation tool. It runs on the developer's own machine and is not offered as a service to third parties.

Data collected

The application receives a TikTok OAuth access token after the developer authorizes it via TikTok's standard consent flow. The token is stored locally on the developer's machine and used only to upload videos to the authorizing TikTok account.

Data sharing

No data is shared with any third party. The application does not collect analytics, telemetry, or usage data from any user other than the developer.

Data retention

The OAuth token is retained locally until the developer revokes it via TikTok's app management page or manually clears it.

Contact

For questions, contact the developer through GitHub at github.com/rndbblnn.
