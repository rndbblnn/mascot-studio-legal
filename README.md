# mascot-studio-legal

Static GitHub Pages site hosting the Terms of Service and Privacy Policy
for the [Mascot Studio](https://github.com/rndbblnn/mascot-studio) personal-use
automation project. Used to satisfy TikTok dev-app registration's URL
ownership verification.

Live at <https://rndbblnn.github.io/mascot-studio-legal/>.

## Files

- `index.html` — landing page with links
- `tos.html` — Terms of Service
- `privacy.html` — Privacy Policy

## Verification files

Files matching `tiktok-developers-site-verification*.txt` (or similar
verification challenge files from other platforms) are committed at the
repo root so they're served at `/<file>` for URL-prefix verification.
